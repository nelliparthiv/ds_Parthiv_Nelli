# ds_Parthiv_Nelli

Project Overview

The project analyzes the relationship between trade behaviour and market sentiment.

Folders 

1. notebook_1.ipynb - Google Colab notebook with full program
2. csv_files - It contains all the csv files generated from the program 
3. outputs - It contains outputs generated from the program i.e., charts
